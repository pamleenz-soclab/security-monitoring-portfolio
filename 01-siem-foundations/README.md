# Month 1 - SIEM Foundations

This folder contains the first stage of the security monitoring portfolio. The focus is building a basic Wazuh SIEM / XDR lab, validating endpoint log collection, and completing the first SOC-style alert investigation.

## Scenarios

| Scenario | Title | Focus |
|---|---|---|
| Scenario 01 | SSH Invalid User Authentication Attempt Investigation | Wazuh pipeline validation, raw log validation, alert triage, and evidence handling |

## Skills Demonstrated

- Wazuh SIEM / XDR lab setup
- Linux authentication log validation
- Wazuh agent log collection
- SOC-style triage reporting
- Investigation report writing
- Sanitized evidence organization
